# Текст чата — доступные сообщения и сводка ранней части

**Объём:** ниже сохранён доступный текст сообщения пользователя, ответа и промежуточного сообщения по Proxmox. Более ранний диалог был сокращён до сводки: его содержание перенесено отдельно, без придуманных реплик или дат. Служебные сообщения, вывод инструментов и учётные данные не являются частью этой стенограммы. Старые ссылки `sandbox:` сохранены в цитате, но в новом диалоге файлы нужно брать из папки передачи.

## 1. Ранняя часть — сводка, не дословная переписка

1. Работа началась с выпуска программ вебинаров по карточкам «Кодекса». Из Dropbox `/Arena/Webinar` были изучены стартовый комплект, бланк, эталонные Word и правила оформления. Сделан первый генератор `webinar_generator`, подготовлен набор из 9 программ и выданы `webinar-programs-2026.zip` и `webinar-generator.zip`.
2. Затем пользователь запросил оформление под ЦМК. Сформирован образец «20 ноября - Новые условия подключения к сетям ЖКХ.docx» по карточке `/tpk`; переданный пользователю образец отличается от исходного эталона, скачанного из Dropbox. Создан отдельный генератор `webinar_cmk_generator`, подготовлена редактура, настроен полный проход по карточкам. Девять карточек на главной оказались не полным списком: тестовый полный обход нашёл 16.
3. Для повседневной работы появился веб-интерфейс: каталог, детализация, выбор карточек, выгрузка, открытие исходной программы и запуск с Windows. Пользователь уточнил: «Даже одиночно» нужны оба варианта: «Скачать Word» и «Скачать zip». Внутри ZIP должна быть папка с датой и названием. Дословный пример: «18 декабря - Оплата труда медицинских работников в 2027 году». Для нескольких карточек — общий ZIP и отдельные ссылки на Word.
4. Пользователь попросил, чтобы парсер запоминал сформированные программы и подсвечивал новые. Добавлены SQLite-история, статусы, сохранённый Word и первичная загрузка снимка без уведомлений по всем старым карточкам.
5. Был запрошен watchdog: три проверки в день с 07 до 20, уведомления пользователю в Telegram. Выбраны слоты **07:00, 13:30 и 20:00 МСК**. Пользователь передавал токен только для теста с планом заменить его; сам токен не сохранён. Реальная отправка Telegram в этих проверках не подтверждена; логика проверена с имитацией Bot API.
6. По просьбе пользователя управление Telegram встроено в веб-интерфейс. Подготовлены служба systemd и инструкция Linux VPS, добавлена возможность назначать и менять порт. Для VPS административный доступ — локальный или через SSH-туннель. Выдан `webinar-generator-cmk-vps.zip`.
7. На вопрос о Proxmox пользователь выбрал **«Создать новый LXC»** и **«Напрямую по IP контейнера»**. Был выбран непривилегированный Debian LXC, Caddy с HTTPS и паролем, генератор на loopback. Доступа к узлу пользователя не было, его CTID и IP не сообщались.

Сохранившаяся точная фраза пользователя по Proxmox: «Давай запустим егло в контейнере на proxmox в локальной сети».

## 2. Развёртывание на Proxmox — доступный текст

### Ассистент — промежуточное сообщение

Проверил HTTPS-вход на тестовом стенде: без пароля панель закрыта, а после входа можно управлять мониторингом. Теперь проверю смену порта и соберу архив для вашего LXC.

### Ассистент — доступный фрагмент ответа

Ответ в интерфейсе отмечен остановленным. Ниже — только текст, доступный при переносе; не предполагается, что был отправлен какой-либо дополнительный текст. Наличие ZIP проверено отдельно по файлам.

Готов [архив генератора ЦМК для Proxmox LXC](sandbox:/home/user/webinar-generator-cmk-proxmox.zip). Панель будет открываться **напрямую по IP контейнера, по HTTPS и с паролем**, без SSH-туннеля. Вход, выгрузку Word и ZIP и смену порта я проверил на тестовом стенде. На вашем Proxmox контейнер пока не создан.

### Как запустить

**1.** В Proxmox создайте и запустите **непривилегированный LXC с Debian 12 или 13**. Подключите его к мосту вашей локальной сети, закрепите за ним IPv4 и включите **Start at boot**. В [полной инструкции](sandbox:/home/user/webinar_cmk_generator/Proxmox-LXC.md) есть команды для создания контейнера из Shell.

**2.** С компьютера передайте скачанный архив на узел Proxmox:

```bash
scp webinar-generator-cmk-proxmox.zip root@IP_УЗЛА_PROXMOX:/root/
```

Затем в **Shell узла Proxmox** подставьте свой CTID вместо `120`:

```bash
CTID=120
pct exec "$CTID" -- ip -4 -br addr
pct push "$CTID" /root/webinar-generator-cmk-proxmox.zip /root/webinar-generator-cmk-proxmox.zip
pct enter "$CTID"
```

**3.** Уже **внутри контейнера** замените `192.168.1.50` на фактический IP из предыдущего шага:

```bash
apt update && apt install -y unzip
unzip -q -o /root/webinar-generator-cmk-proxmox.zip -d /root/cmk-release
cd /root/cmk-release/webinar_cmk_generator
bash deploy/install-lxc.sh --ip 192.168.1.50 --port 8443
```

Установщик попросит задать отдельный пароль для панели. Логин по умолчанию — `cmk`.

**Перед первым входом** перенесите публичный сертификат `root.crt` на свой компьютер, сверьте его SHA‑256 и добавьте в доверенные по [инструкции](sandbox:/home/user/webinar_cmk_generator/Proxmox-LXC.md#3-доверьтесь-сертификату-своего-контейнера-и-откройте-панель). Затем откройте `https://IP_КОНТЕЙНЕРА:8443/`. Не вводите пароль или токен, пока браузер показывает предупреждение о сертификате. Порт в интернет не пробрасывайте.

В панели откройте **«Мониторинг»**, привяжите бота с **новым токеном** и после тестового сообщения включите расписание. Проверки идут в **07:00, 13:30 и 20:00 МСК** даже при закрытом браузере. В Telegram отправляются только новые карточки. Если понадобится другой HTTPS-порт, выполните внутри LXC `cmk-lan-config port 9443`.
